## Conventions
- One self-contained static `index.html` per folder (inline CSS/JS; CDN libs allowed). No build step.
- Every booking CTA links to `https://wa.me/<number>` using that business's own WhatsApp number (see briefs).
- EN/AR toggle where present; Arabic must switch to `dir="rtl"` cleanly.
